# compatibility-tool

The compatibility verification tool can be used to add environment resources based on FusionCube or FusionCompute, create compatibility verification tasks, and support function, performance, reliability, and stability tests. It can automatically detect the environment, deploy VMs, and execute tests. After the test is complete, you can download the test report. This tool supports multiple versions of FusionCube or FusionCompute and different architectures (x86, C86, and ARM).

## Compatibility Tool

Main tool package. After downloading the package, use the 7-Zip tool to combine it.

## VM Template

Download the software package based on the CPU instruction set architecture. The Windows template needs to be merged using the 7-ZIP tool.
